# UTS — START HERE

Project sudah lengkap dan runnable. Jangan membuat project baru.

## 1. Jalankan
```bash
docker compose up -d --build
docker compose ps
```

Buka `http://localhost:8080`.

## 2. Yang sudah tersedia
- Flask Web
- PostgreSQL
- Dockerfile
- Docker Compose
- Docker Network
- Docker Volume
- Class `Student`
- Class `RiskService`
- Dashboard
- Daftar student
- Filter risk

## 3. Aturan pengerjaan
1. Gunakan repository ini.
2. Buat branch untuk pekerjaan UTS.
3. Jangan menghilangkan fungsi utama.
4. Aplikasi harus tetap berjalan.
5. Docker harus tetap dapat digunakan.
6. Commit perubahan secara bertahap.
7. Siapkan repository untuk pemeriksaan.

## 4. Pemeriksaan
```bash
git status
git branch
git log --oneline
docker compose ps
```

Kemudian jalankan aplikasi dan tunjukkan perubahan yang dibuat.
